#### FreeBSD Boot Sequence (no network needed)
```
<esc><wait>                    # Escape boot menu
boot -s<enter>                 # Single-user mode
<wait15s>                      # Wait for kernel
/bin/sh<enter><wait>           # Start shell
mdmfs -s 100m md /tmp          # Writable /tmp
mount_cd9660 /dev/cd1 /mnt ... # Mount config CD (cd0=installer, cd1=config)
bsdinstall script /mnt/installerconfig
```

#### FreeBSD installerconfig Structure
- **Preamble**: auto-detect disk (vtbd0/ada0/da0/nvd0), UFS PARTITIONS, base.txz+kernel.txz
- **Post-install** (chrooted): hostname, conditional network (static via iface detect or DHCP via ifconfig_DEFAULT), SSH with root login, SHA-512 password hash via `pw usermod root -H 0`, sendmail disabled, NTP, fast boot
- FreeBSD NIC names are driver-based (vtnet0/em0/vmx0) — no normalization like Linux's net.ifnames=0
- `ifconfig_DEFAULT=DHCP` works across all drivers for DHCP
- For static: detect first non-loopback iface with shell loop, then sysrc
- pre_provisioner installs Python 3 via `pkg bootstrap` + `pkg install` after first boot (needed for Ansible)

#### FreeBSD ISO URLs
- Pattern: `https://download.freebsd.org/releases/>>bsd_arch<</>>bsd_arch<</ISO-IMAGES/>>version<</FreeBSD->>version<<-RELEASE->>bsd_arch<<-disc1.iso`
- FreeBSD only keeps latest releases on download.freebsd.org — old versions archived
- 14.2 already gone (404), 14.3/14.4/15.0 available as of 2026-03-10
- `bsd_arch` def maps x86_64 → amd64
